# Netflix Movie Recommendation System

## Project Overview
This project is a Movie Recommendation System developed using machine learning techniques to recommend similar movies based on user preferences and movie content.

The system analyzes movie metadata such as genres, keywords, cast, crew, and overview to recommend movies similar to the selected movie.

The main goal of this project is to improve user experience by providing personalized movie recommendations.

---

## Problem Statement
With thousands of movies available on streaming platforms, users often struggle to find movies that match their interests.

This project solves this problem by building a recommendation system that suggests similar movies based on movie content and similarity analysis.

---

## Objectives
- Build a movie recommendation system
- Recommend similar movies based on user selection
- Perform data cleaning and preprocessing
- Apply Natural Language Processing techniques
- Generate similarity scores between movies
- Improve personalized movie discovery
